평일 07:48 · GitHub Actions (무료)
GitHub에서 보기 ↗
앱에서 켜고 끄려면: GitHub 토큰 연결

이 저장소의 Actions 권한만 가진 토큰을 한 번 넣어 두면, 앱에서 바로 자동 수집을 켜고 끄거나 지금 수집할 수 있어요. 토큰은 이 기기의 브라우저에만 저장돼요.

  1. GitHub 토큰 만들기 ↗ (Fine-grained token)
  2. Repository access: Only select repositories → 이 저장소만 선택
  3. Permissions → Repository permissions → Actions: Read and write
  4. Generate token 후 나온 값을 아래에 붙여넣기

켜 두면 평일 아침 7:48에 GitHub Actions가 뉴스를 모아요. 무료이고 Claude 사용량은 들지 않아요.

뉴스는 평일 아침 Google 뉴스에서 테마별로 자동 수집됩니다. 체크포인트는 그날 주요 헤드라인 3개이고, 호재·악재 표시는 제목 단어로 자동 분류한 것이라 틀릴 수 있어요. 보고 싶은 테마는 '＋ 테마 선택'에서 켜고 끌 수 있어요. 앱에서 직접 만든 테마는 자동 수집 대상이 아니에요. 투자 판단의 근거가 아닌 참고용입니다.
